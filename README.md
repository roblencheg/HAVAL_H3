# GWM RU for Home Assistant

Неофициальная интеграция Home Assistant для российского облака GWM / HAVAL / TANK / ORA / WEY с мониторингом и удалённым управлением автомобилем.

Проверено на **Haval H3** через российское приложение GWM 2.3.1.

## Возможности

### Мониторинг

- Поддержка **нескольких автомобилей** в одном аккаунте GWM
- Автоматическое определение доступных функций автомобиля через capability API GWM
- Общий статус автомобиля: `Запущена`, `Открыта`, `На охране`, `Неизвестно`
- Статус двигателя, центрального замка, дверей и багажника
- Статус всех четырёх окон и люка
- Статус климата
- Статус обогрева заднего стекла, руля и лобового стекла
- Уровни подогрева водительского и пассажирского сидений
- Передний дефрост
- Запас хода, уровень топлива и пробег
- Давление и температура шин
- Отдельные TPMS-сигналы ошибок давления и температуры каждого колеса
- GPS и `device_tracker`
- TBOX online
- История удалённых команд
- Статус последней удалённой команды: `Выполняется`, `Успешно`, `Ошибка`

> [!NOTE]
> Набор сущностей зависит от capability конкретного автомобиля и данных, которые возвращает российское облако GWM.

### Удалённое управление

Для команд требуется PIN-код безопасности из приложения GWM и включённая опция **«Включить удалённое управление»**.

Поддерживаются:

- Запуск двигателя с временем работы
- Остановка двигателя
- Блокировка / разблокировка дверей
- Открытие / закрытие багажника
- Закрытие окон
- Закрытие люка
- Климат: включение, выключение и целевая температура
- Обогрев заднего стекла
- Обогрев руля
- Обогрев лобового стекла
- Подогрев водительского сиденья: `Выкл / 1 / 2 / 3`
- Подогрев пассажирского сиденья: `Выкл / 1 / 2 / 3`
- Фары / звуковой сигнал
- Принудительное обновление данных

Рабочие функции создаются только если соответствующая capability заявлена автомобилем.

## Climate entity

Интеграция создаёт полноценную сущность `climate` для автомобиля.

Она позволяет:

- включать и выключать климат;
- задавать температуру от 16 до 32 °C;
- видеть текущее состояние климата;
- использовать климат в стандартных карточках и автоматизациях Home Assistant.

Управление использует T5-команду GWM `0x04`.

## Подогрев сидений

Если автомобиль поддерживает дистанционное управление сиденьями, создаются две сущности `select`:

- `Обогрев водительского сиденья`
- `Обогрев пассажирского сиденья`

Доступные значения:

- `Выкл`
- `1`
- `2`
- `3`

Интеграция использует T5-команду `0x0A` и учитывает расположение руля автомобиля при сопоставлении водительского и пассажирского сидений с физическими `leftFront` / `rightFront`.

## Несколько автомобилей

Если к аккаунту GWM привязано несколько машин, интеграция создаёт отдельное устройство Home Assistant для каждой.

Для первой машины сохраняются прежние unique ID сущностей, чтобы обновление не создавало дубликаты. Для дополнительных машин идентификаторы строятся по VIN.

Кнопки, переключатели, `select` и другие управляющие сущности автоматически отправляют команду именно той машине, к которой относятся.

При ручном вызове сервиса без `vin` команда отправляется первой машине аккаунта. При необходимости можно передать `vin` в service data.

## Диагностика

Откройте:

**Настройки → Устройства и службы → GWM RU → Скачать диагностику**

Перед выдачей диагностических данных интеграция скрывает чувствительные данные и идентификаторы, включая пароль, PIN, токены, телефон, VIN, IMSI / ICCID, номер двигателя, device ID, `unique_id`, `shareId`, `vehicleId` и `templateId`.

Диагностика содержит:

- сырые `code/value` из `getLastStatus` без чувствительных идентификаторов;
- верхнеуровневые поля статуса автомобиля;
- capabilities автомобиля;
- тип и результат последней T5-команды;
- текущие разобранные состояния автомобиля.

Стабильная версия не выполняет исследовательские read-only probes при скачивании диагностики.

## Установка

### HACS

[![Open your Home Assistant instance and open this repository inside the Home Assistant Community Store.](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=roblencheg&repository=HAVAL_H3&category=integration)

1. Откройте **HACS → Integrations → ⋮ → Custom repositories**
2. Repository: `https://github.com/roblencheg/HAVAL_H3`
3. Category: `Integration`
4. Установите **GWM RU**
5. Перезапустите Home Assistant

### Вручную

1. Скопируйте `custom_components/gwm_ru` в `/config/custom_components/gwm_ru`
2. Перезапустите Home Assistant

## Настройка

[![Open your Home Assistant instance and start configuring the GWM RU integration.](https://my.home-assistant.io/badges/config_flow_start.svg)](https://my.home-assistant.io/redirect/config_flow_start/?domain=gwm_ru)

1. **Настройки → Устройства и службы → Добавить интеграцию → GWM RU**
2. Введите номер телефона GWM
3. Введите пароль
4. При необходимости сохраните PIN-код безопасности

В настройках интеграции доступны:

- **Poll interval** — период обновления, по умолчанию 300 секунд
- **Включить удалённое управление**
- **Command cooldown** — задержка между удалёнными командами, по умолчанию 5 секунд
- **ПИН из приложения**
- удаление сохранённого PIN

> [!IMPORTANT]
> Рекомендуется использовать отдельный аккаунт GWM и предоставить ему доступ к машине через функцию **«Поделиться автомобилем»**. Один аккаунт, одновременно используемый приложением и Home Assistant, может разлогиниваться.

### Binary sensors

- `TBOX онлайн`
- `Двигатель запущен`
- состояние замка

- багажник
- климат
- четыре окна
- обогрев заднего стекла
- обогрев руля
- обогрев лобового стекла
- передний дефрост
- GPS разрешён

### Switch

- обогрев заднего стекла
- обогрев руля
- обогрев лобового стекла

### Select

- обогрев водительского сиденья: `Выкл / 1 / 2 / 3`
- обогрев пассажирского сиденья: `Выкл / 1 / 2 / 3`

### Climate

- `Климат`
- OFF / COOL
- целевая температура 16–32 °C

### Device tracker

Для каждой машины создаётся GPS `device_tracker`.

## Общий статус автомобиля

| Статус | Условие |
| --- | --- |
| `Запущена` | двигатель считается запущенным |
| `Открыта` | автомобиль разблокирован или открыта дверь / багажник |
| `На охране` | центральный замок закрыт |
| `Неизвестно` | данных недостаточно |

> [!NOTE]
> `На охране` определяется по состоянию центрального замка. Это не отдельный сигнал штатной сигнализации.

После подтверждённого дистанционного запуска или остановки двигателя источник состояния указывается как `remote_command_result`.

## Примеры

### Запуск двигателя

```yaml
action: gwm_ru.engine_start
data:
  operation_time: 15
```

### Остановка двигателя

```yaml
action: gwm_ru.engine_stop
data: {}
```

### Команда конкретной машине

```yaml
action: gwm_ru.engine_start
data:
  vin: "VIN_АВТОМОБИЛЯ"
  operation_time: 15
```

### Управление климатом

```yaml
action: climate.set_temperature
target:
  entity_id: climate.gwm_ru_klimat
data:
  temperature: 22
```

## Безопасность

Удалённое управление выполняет реальные команды через облако GWM.

Не создавайте автоматизации запуска двигателя или разблокировки автомобиля без подходящих условий безопасности.

Пароль и PIN хранятся в конфигурации Home Assistant.

Проект не связан с GWM, HAVAL, TANK, ORA или WEY и использует неофициальный API.
