# GWM RU for Home Assistant

Неофициальная интеграция Home Assistant для российского облака GWM / HAVAL / TANK / ORA / WEY с поддержкой мониторинга и удалённого управления автомобилем.

Проверено на **Haval H3** через российское приложение GWM 2.2.3.

## Возможности

### Мониторинг автомобиля

- **Общий статус автомобиля**: `Запущена`, `Открыта`, `На охране`, `Неизвестно`
- **Статус двигателя**: запущен / остановлен
- **Статус замка** автомобиля
- **Состояние дверей** по отдельности
- **Состояние багажника**
- **Состояние климата**
- Запас хода, уровень топлива, пробег
- Марка, модель и цвет
- Давление и температура в шинах по всем колёсам
- Температура двигателя
- Температура воздуха
- Вольтаж аккумулятора
- Уровень масла и статус обслуживания
- Статус TBOX и доступность автомобиля в облаке
- GPS-трекер: местоположение автомобиля на карте Home Assistant

### Удалённое управление

Для удалённых команд требуется PIN-код безопасности из приложения GWM и включённая опция **«Включить удалённое управление»**.

Поддерживаются:

- **Запустить двигатель** с настраиваемым временем работы
- **Остановить двигатель**
- Заблокировать / разблокировать двери
- Открыть / закрыть багажник
- Закрыть окна
- Открыть / закрыть люк
- Открыть / закрыть шторку люка
- Включить / выключить обогрев заднего стекла
- Включить / выключить обогрев руля
- Моргнуть фарами
- Подать звуковой сигнал
- Фары + сигнал
- Принудительно обновить данные автомобиля

Для поддерживаемых команд создаются кнопки Home Assistant и сервисы `gwm_ru.*`, которые можно использовать в автоматизациях и сценариях.

> [!IMPORTANT]
> Для работы интеграции рекомендуется использовать **отдельный аккаунт GWM**.
>
> В приложении GWM создайте второй аккаунт и предоставьте ему доступ к автомобилю через функцию **«Поделиться автомобилем»**.
>
> Не используйте один и тот же аккаунт одновременно в мобильном приложении и в интеграции. При параллельной работе под одним аккаунтом GWM может разлогинивать пользователя из приложения.
>
> Также установите в приложении GWM **PIN-код безопасности** для чувствительных действий, включая дистанционный запуск двигателя.

## Установка

### Вариант 1: HACS (рекомендуется)

[![Open your Home Assistant instance and open this repository inside the Home Assistant Community Store.](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=roblencheg&repository=HAVAL_H3&category=integration)

1. Откройте **HACS → Integrations → ⋮ → Custom repositories**
2. Repository: `https://github.com/roblencheg/HAVAL_H3`
3. Category: `Integration`
4. Установите **GWM RU**
5. Перезапустите Home Assistant

### Вариант 2: вручную

1. Скопируйте папку `custom_components/gwm_ru` в `/config/custom_components/gwm_ru`
2. Перезапустите Home Assistant

## Настройка

[![Open your Home Assistant instance and start configuring the GWM RU integration.](https://my.home-assistant.io/badges/config_flow_start.svg)](https://my.home-assistant.io/redirect/config_flow_start/?domain=gwm_ru)

### Первичная настройка

1. Откройте **Настройки → Устройства и службы → Добавить интеграцию → GWM RU**
2. Введите телефон в любом поддерживаемом формате: `+7923...`, `7923...`, `8923...` или `923...`
3. Введите пароль от приложения GWM
4. Укажите PIN-код безопасности из приложения GWM, если планируете использовать удалённые команды

### Настройки интеграции

**Настройки → Устройства и службы → GWM RU → Настроить**

- **Poll interval** — периодичность обновления данных в секундах, по умолчанию `300`
- **Включить удалённое управление** — включает кнопки и сервисы управления автомобилем
- **Command cooldown** — минимальная задержка между командами, по умолчанию `30` секунд
- **ПИН из приложения** — PIN-код безопасности GWM
- **Удалить сохранённый ПИН** — удалить сохранённый PIN-код из конфигурации интеграции

### PIN-код безопасности

PIN требуется для отправки удалённых команд. Его можно:

- сохранить в настройках интеграции;
- передавать вручную через поле `security_pin` при вызове сервиса.

> [!WARNING]
> PIN и пароль от учётной записи GWM хранятся в конфигурации Home Assistant. Не публикуйте конфигурационные файлы и диагностические данные, содержащие эти значения.

## Сущности

Интеграция создаёт сущности нескольких типов.

### Сенсоры

В зависимости от данных, которые возвращает автомобиль, доступны:

- `Статус автомобиля`
- `Состояние двигателя`
- `Состояние замка`
- `Запас хода`
- `Топливо`
- `Пробег`
- `Марка`
- `Модель`
- `Цвет`
- давление и температура каждой шины
- температура двигателя
- температура воздуха
- вольтаж аккумулятора
- уровень масла
- статус обслуживания
- статус TBOX

### Binary sensors

- `TBOX онлайн`
- `Двигатель запущен`
- `Автомобиль закрыт`
- `Багажник открыт`
- `Передняя левая дверь открыта`
- `Передняя правая дверь открыта`
- `Задняя левая дверь открыта`
- `Задняя правая дверь открыта`
- `Климат включён`

### Device tracker

Интеграция создаёт GPS `device_tracker` с текущими координатами автомобиля, если облако GWM возвращает координаты.

## Общий статус автомобиля

Интеграция формирует удобный текстовый статус для карточек Home Assistant:

| Статус | Условие |
| --- | --- |
| `Запущена` | двигатель работает |
| `Открыта` | автомобиль разблокирован или открыта дверь / багажник |
| `На охране` | автомобиль заблокирован |
| `Неизвестно` | облако не вернуло достаточно данных для определения состояния |

> [!NOTE]
> Статус `На охране` сейчас определяется по состоянию центрального замка. Это не отдельный диагностический признак штатной сигнализации.

## Удалённое управление

Если включена опция удалённого управления и сохранён PIN-код, интеграция создаёт кнопки для поддерживаемых команд.

Команды выполняются сразу, без дополнительного подтверждения в Home Assistant.

Защита от слишком частой отправки команд:

- используется настраиваемый `command_cooldown`;
- по умолчанию между командами должно пройти не менее 30 секунд;
- после успешной команды интеграция запрашивает обновлённое состояние автомобиля.

### Запуск двигателя

Сервис:

```yaml
action: gwm_ru.engine_start
data:
  operation_time: 15
```

`operation_time` — время удалённой работы двигателя в минутах. По умолчанию используется `15`.

### Остановка двигателя

```yaml
action: gwm_ru.engine_stop
data: {}
```

## Примеры автоматизаций

> Если PIN сохранён в настройках интеграции, `security_pin` в автоматизациях можно не указывать.

### Запустить двигатель перед выходом утром

```yaml
alias: "Прогреть Haval утром"
triggers:
  - trigger: time
    at: "07:30:00"
conditions:
  - condition: state
    entity_id: binary_sensor.gwm_ru_avtomobil_zakryt
    state: "on"
actions:
  - action: gwm_ru.engine_start
    data:
      operation_time: 15
```

### Остановить двигатель

```yaml
alias: "Остановить удалённый запуск"
triggers:
  - trigger: state
    entity_id: person.my_phone
    to: "home"
actions:
  - action: gwm_ru.engine_stop
    data: {}
```

### Закрывать машину каждый вечер

```yaml
alias: "Закрыть авто в 23:00"
triggers:
  - trigger: time
    at: "23:00:00"
conditions:
  - condition: state
    entity_id: person.my_phone
    state: "home"
actions:
  - action: gwm_ru.lock_vehicle
    data: {}
```

### Закрывать окна при уходе из дома

```yaml
alias: "Закрыть окна при уходе"
triggers:
  - trigger: state
    entity_id: person.my_phone
    to: "not_home"
actions:
  - action: gwm_ru.close_windows
    data: {}
```

### Включать обогрев руля по температуре

```yaml
alias: "Обогрев руля по температуре"
triggers:
  - trigger: numeric_state
    entity_id: sensor.gwm_ru_ambient_temperature
    below: 0
actions:
  - action: gwm_ru.steering_wheel_heat_on
    data:
      operation_time: 20
```

## Безопасность

Удалённое управление автомобилем выполняет реальные команды через облако GWM.

Перед использованием автоматизаций с запуском двигателя, разблокировкой дверей и другими чувствительными действиями убедитесь, что сценарии не могут сработать случайно.

Проект не связан с GWM, HAVAL, TANK, ORA или WEY и использует неофициальный API. Используйте интеграцию на свой риск.
