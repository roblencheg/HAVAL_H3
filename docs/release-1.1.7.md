# v1.1.7 — восстановление сессии

Стабильный релиз исправляет ошибку «Срок действия токена входа истек», после которой раньше требовалась перезагрузка интеграции. Проблема описана пользователем в PR #13; исправление реализовано отдельно с проверкой конкурентных запросов.

- Распознаются явные ошибки сессии, русскоязычное сообщение об истечении токена и HTTP 401, включая ответы без JSON.
- Интеграция обновляет токен и один раз повторяет исходный запрос с прежними параметрами, телом и VIN.
- Одновременные ответы со старым токеном используют уже восстановленную сессию. Поздний ответ не сбрасывает новый токен и не запускает лишний вход.
- Повторный отказ авторизации передаётся Home Assistant; бесконечного цикла входа нет. Ошибки прав и другие ошибки облака не считаются истечением сессии только из-за упоминания токена или префикса кода.
- Ответ входа без accessToken корректно обрабатывается как ошибка авторизации.

Проверки: 36 backend-тестов с настоящими aiohttp и voluptuous, включая конкурентное восстановление, повторный отказ, HTTP 401 и валидацию температуры; проверки синтаксиса, карточек в Chromium, HACS и Hassfest выполняются перед публикацией. Тесты используют имитацию облака и не отправляют команды автомобилю.

Обновление: установить v1.1.7 через HACS и перезапустить Home Assistant. Настройки интеграции сохраняются.
