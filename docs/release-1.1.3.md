## Пульты Remote Studio

- Исправлен отступ перед нижней строкой «Шины / Запас хода» горизонтального анимированного пульта: плитки больше не слипаются.
- Исправлен переход горизонтального пульта к вертикальной компоновке в узких секциях.
- Добавлены две отдельные карточки **Studio · вертикальный** и **Studio · горизонтальный**: выразительные кнопки, крупная сцена автомобиля, статус подключения и отдельная телеметрия.
- Новые пульты наследуют тему Home Assistant, поддерживают узкие экраны, клавиатурный фокус и отключение анимаций через системную настройку reduced motion.
- Сохранены существующие команды, визуальный редактор, выбор устройства, подтверждения и блокировка кнопок при выполнении команды.
- Все карточки загружаются автоматически через общий module resource; версии ресурсов обновлены для сброса кэша.

### Как добавить
Обновите интеграцию в HACS, перезапустите Home Assistant и обновите страницу Dashboard. В меню добавления карточек выберите **GWM RU — Studio · вертикальный** или **GWM RU — Studio · горизонтальный**.

```yaml
type: custom:gwm-vehicle-remote-modern-card
```

```yaml
type: custom:gwm-vehicle-remote-modern-horizontal-card
```

Существующие карточки продолжат работать без изменения YAML.
