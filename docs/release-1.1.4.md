## Единая телеметрия пультов

- Статусные плитки и дополнительная информация объединены в один блок. Климат, топливо, пробег и другие повторяющиеся элементы показываются один раз.
- В визуальном редакторе используется общий список «Состояние и информация».
- GSM — опциональная плитка общего списка, без повторения в шапке; по умолчанию скрыта.
- Из обеих карточек Studio убрана надпись «GWM / Remote Studio».
- Название всех пультов необязательно. Пустое поле или пробелы скрывают заголовок.
- Существующие YAML-списки `statuses` и `info` поддерживаются и объединяются автоматически. Для нового общего списка используйте `telemetry`.

Обновите интеграцию через HACS, перезапустите Home Assistant и обновите Dashboard.
